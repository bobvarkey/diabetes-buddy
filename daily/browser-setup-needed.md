## Setup Instructions (One-Time)

1. Open Chrome manually
2. Navigate to `chrome://inspect/#remote-debugging`
3. Check the checkbox to **"Enable remote debugging"**
4. If prompted, click "Allow" to grant permission
5. Close Chrome

This setting persists across restarts for your Chrome profile.

## Alternative Solutions


### Option B: Dedicated Automation Profile
Create a separate Chrome profile for automation:
```bash
# Launch Chrome with remote debugging on a different port
/Applications/Google\ Chrome.app/Contents/MacOS/Google\ Chrome \
  --user-data-dir=/tmp/chrome-automation \
  --remote-debugging-port=9222
```
